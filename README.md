# 原点工作室 · ORIGIN LAB

面向大学新生的技术实践与职业成长工作室招募网站。

## 本地开发

```bash
npm install
npm run dev
```

## 内容替换

- 微信二维码：替换 `App.tsx` 中的二维码占位区域。
- 报名表：替换弹窗中的外部报名链接。
- 项目素材：将图片放入 `public/projects/`，并替换项目卡片占位内容。
- 工作室照片：将图片放入 `public/studio/`。

## GitHub Pages

推送到 `main` 分支后，工作流会自动构建和发布。首次使用时需在仓库 Settings → Pages 中选择 GitHub Actions 作为来源。
